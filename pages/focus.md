# Focus

I'm interested in **AI agents and the infrastructure that helps them work reliably**. Below are the areas I'm exploring, alongside selected projects from my [GitHub stars](https://github.com/xUxIAOrUI815?tab=stars) that I follow and learn from.

## Agent Systems

Agent loops, tool use, context, and sandboxed execution for tasks that can recover from failure and continue.

- [LangGraph](https://github.com/langchain-ai/langgraph) — Stateful agent orchestration.
- [Deep Agents](https://github.com/langchain-ai/deepagents) — Agent harnesses for complex tasks.
- [E2B](https://github.com/e2b-dev/E2B) — Sandboxed environments for agents.

## Quality & Feedback

Connecting traces and evaluations to understand failures and assess improvements in agent behavior.

- [Langfuse](https://github.com/langfuse/langfuse) — LLM observability and evaluation.
- [Inspect AI](https://github.com/UKGovernmentBEIS/inspect_ai) — A framework for language model evaluation.
- [τ-bench](https://github.com/sierra-research/tau-bench) — Evaluation of agents interacting with users and tools.

## Coding Agents

Agent harnesses, reusable skills, and development workflows with changes that can be inspected and validated.

- [Codex](https://github.com/openai/codex) — A coding agent that runs in the terminal.
- [Agent Skills](https://github.com/anthropics/skills) — Reusable skills for agents.
- [mini-SWE-agent](https://github.com/SWE-agent/mini-swe-agent) — A minimal software engineering agent.

## Knowledge & Research

Retrieval, agent memory, and context engineering for research grounded in sources.

- [RAGFlow](https://github.com/infiniflow/ragflow) — Retrieval-augmented generation and agent capabilities.
- [OpenViking](https://github.com/volcengine/OpenViking) — Context management for agent memory, knowledge, and skills.
- [DeerFlow](https://github.com/bytedance/deer-flow) — A harness for research and other long-running agent tasks.

## Models & Post-training

Learning how language models are built, fine-tuned, and improved through reinforcement learning.

- [LLMs from Scratch](https://github.com/rasbt/LLMs-from-scratch) — Building language models step by step.
- [LlamaFactory](https://github.com/hiyouga/LlamaFactory) — Fine-tuning language and vision-language models.
- [verl](https://github.com/verl-project/verl) — Reinforcement learning for model post-training.

## Inference & GPU Performance

Exploring inference serving, KV cache, and GPU programming across latency, throughput, and memory trade-offs.

- [vLLM](https://github.com/vllm-project/vllm) — LLM inference and serving.
- [Mooncake](https://github.com/kvcache-ai/Mooncake) — A serving platform with a focus on KV cache infrastructure.
- [Triton](https://github.com/triton-lang/triton) — GPU programming language and compiler.
